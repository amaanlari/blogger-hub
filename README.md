# Blogger Hub

Blogger Hub is a comprehensive blogging platform that enables users to create, manage, and share blogs seamlessly. This repository contains both the backend API (**Spring Boot** + **MongoDB**) and a **React + TypeScript** frontend, built and packaged together into a single deployable JAR.

## Features

- **User Module**
    - User registration and login (JWT-based authentication)
    - User profile management
    - Follow and unfollow users

- **Blog Module**
    - Create, update, delete, and view blogs
    - Like and comment on blogs
    - Support for threaded replies in comments

- **Media Management**
    - Store profile pictures and blog images using **Cloudinary**

- **Database**
    - MongoDB for managing users, blogs, and interactions

#### Features in Progress
- **User Follow Feature**
    - Follow and unfollow users

- **Notification Module**
    - Real-time notifications using queuing system (RabbitMQ or Apache Kafka etc.)
    - Notifications for likes, comments, and follows

## Tech Stack

- **Backend Framework**: Spring Boot
- **Frontend**: React + TypeScript (Vite) — see [`docs/FRONTEND.md`](docs/FRONTEND.md)
- **Database**: MongoDB (with migration plans to DynamoDB)
- **File Storage**: Cloudinary
- **Build Tool**: Maven (frontend build is orchestrated by Maven too, via `frontend-maven-plugin`)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/blogger-hub.git
   cd blogger-hub
   ```

2. Update the `application.yml` file with your MongoDB and Cloudinary credentials.

3. Build the project (also builds the React frontend and bundles it into the JAR — requires
   internet access on first run to download a project-local Node/npm, see
   [`docs/FRONTEND.md`](docs/FRONTEND.md#maven-integration)):
   ```bash
   mvn clean install
   ```
   To skip the frontend build entirely (backend-only iteration): `mvn clean install -DskipFrontend=true`.

4. Run the application:
   ```bash
   mvn spring-boot:run
   ```
   This serves both the API (`/api/**`) and the React app (everything else) on the same port.

   For frontend development with hot-reload instead, run the backend as above and, in a second
   terminal: `cd frontend && npm install && npm run dev` (see
   [`docs/FRONTEND.md`](docs/FRONTEND.md#development-setup)).

## API Documentation

The full REST API contract — every endpoint, request/response shape, auth rule, and known
backend quirk — is documented in [`docs/API_CONTRACT.md`](docs/API_CONTRACT.md), generated
directly from the current controller/service implementation (there is no Swagger/OpenAPI UI
wired up in this project despite some legacy references to one in the security config).

## Development Setup

### Prerequisites

- Java 17 or higher
- MongoDB installed locally or accessible via cloud
- Kafka broker setup (local or cloud)

### Configuration

The application uses profiles for different environments. Set the active profile as needed using the follwing:
```bash
  -Dspring.profiles.active=<profile>

                    OR

  -Dspring-boot.run.profiles=<profile>
```
